# Zugversuch: Prüfstand für bistabile Metamaterialien

Hauptprojekt im Studiengang MPEC (Maschinenbau Product Engineering and Context)
Technische Hochschule Köln · Sommersemester 2026 · Team 42

## Über das Projekt

Im Rahmen unseres Hauptprojekts haben wir einen Zugprüfstand entwickelt, mit dem sich bistabile mechanische Metamaterialien experimentell untersuchen lassen. Mit dem Prüfstand haben wir den Einfluss des Stegwinkels auf die Durchschnappkraft eines 3D-gedruckten TPU-Metamaterials untersucht.

## Inhalt dieses Repositories

- Materialspezifikationen des verwendeten TPU
- Code zur Programmierung des Prüfstands
- Detaillierter Aufbau des Prüfstands
- Druckparameter (Bambu Lab P1S)
- Technische Zeichnung der bistabilen Struktur
